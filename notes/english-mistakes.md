# 常犯英文错误清单

[⬅️ 返回目录](../README.md)

| ❌ 错误 | ✅ 正确 | 说明 |
|---|---|---|
| No worried | **Don't worry** | 固定说法 |
| i am Eleven（电话中） | **This is Eleven** | 电话自我介绍用 *This is* |
| it department | **the IT department** | 缩写大写，前面加 *the* |
| right way | **right away** | *right away* = 马上 |
| a few question quick | **a few quick questions** | 形容词在前，名词复数 |
| cannot sending | **cannot send** | *can / will / should* 后接动词原形 |
| I'll helping | **I'll help** | 同上 |
| you have connect | **you're connected** | *have* 后接过去分词 |
| I've connect | **I'm connected / I've connected** | 同上 |
| I have already unlock | **I've unlocked** | 同上 |
| log in / logging 混用 | **log in**（动词） | *logging* 只用在进行式 |
| in hurry | **in a hurry** | 固定说法 |
| for the security reason | **for security reasons** | 固定说法 |
| sorry for waiting | **Thanks for waiting / Sorry for keeping you waiting** | 原句意思是"我在等" |
| do you mind i connect | **Do you mind if I connect / Is it okay if I connect** | 回答 *Do you mind?* 时，*No* = 可以 |
| by remote | **remotely** | 固定说法 |
| the another choice | **another choice / the other choice** | *the* 和 *another* 不能并用 |
| print query | **print queue** | *queue* 队列，*query* 查询 |
| tap | **tab** | *tab* 标签页，*tap* 轻触 |
| jam（队列卡住） | **stuck in the print queue** | *paper jam* 是卡纸 |
| linking to the printer | **selected / sent to the printer** | *link* 多用于网址、账号 |
| call to your supervisor | **call your manager** | *call* 后直接接人 |
| ensure your information | **verify your identity** | *ensure* = 确保 |
| you register phone number | **your registered phone number** | 所有格 + 过去分词 |
| posiblem / identidy / appreal | **possible / identity / appears** | 拼写 |
| please unplugged | **please unplug** | *please* 后接动词原形 |
| Thanks for inform me | **Thanks for letting me know** | *for* 后接动词 ing |
| help me to type | **Please type** | 是用户在帮自己 |
| share drive | **shared drive** | 共享的硬盘 |
| when is the situation start | **When did this problem start?** | 问过去的事用 *did* + 原形 |
| you uses | **you use** | *you* 后的动词不加 *s* |
| didn't got | **didn't get** | *didn't* 后接原形 |
| the relate team | **the network team / the related team** | 具体说出团队名称更专业 |
| serach / colleageus / troubeshooting | **search / colleagues / troubleshooting** | 拼写 |
| help you with right away | **help you right away** | *help you with* 后要接事情 |
| specially application | **specific / certain applications** | 这里要用形容词 |
| Are you open a lot of application | **Do you have a lot of applications open?** | *have ... open* |
| by go to | **by going to** | *by* 后接动词 ing |
| continue where you left on | **Continue where you left off** | 选项名称要准确 |
| quit full | **quite full** | *quit* 放弃，*quite* 相当 |
| usage is full | **storage / disk is full** | *usage* 不能"满" |
| I suggest you to click | **I suggest clicking / I suggest (that) you click** | *suggest* 不接 *you to* |
| unclick | **uncheck** | 取消勾选 |
| prevent to delete | **prevent ... from deleting / so you don't delete** | *prevent from + ing* |
| pop out | **pop up / open** | 窗口跳出来 |
| delete the tabs | **close the tabs** | 分页是关闭 |
| the file won't delete | **the file won't be deleted** | 被动语态 |
| on the cloud | **in the cloud** | 固定说法 |
| there has a function call | **there is a feature called** | *there is* + *called* |
| was loaded slow | **was running slowly** | 电脑运行得慢 |
| log in your account | **log in to your account** | *log in to* + 地方 |
| sign out of all your sessions（IT 帮用户） | **sign you out of all your sessions** | 帮别人登出要加 *you* |
| in the outlook | **in Outlook** | 产品名称不加 *the* |
| You are doing well as call us | **You did a great job calling us** | 过去式 + *calling* |
| did you received / I just send | **did you receive / I just sent** | *did* + 原形；过去式 |
| was going to expired | **was going to expire** | *going to* + 原形 |
| identify the user identity | **verified the user's identity** | 验证用 *verify* |
| ask user don't approve | **asked the user not to approve** | *ask someone not to do* |
| an email said | **an email saying** | 描述邮件内容 |
| reser / loggin / ahamd | **reset / login / Ahmad** | 拼写（名字要特别注意！） |
| won't happened / didn't happened | **won't happen / didn't happen** | *won't / didn't* 后接原形 |
| save works | **save your work** | *work* 不可数；*works* 是"作品" |
| before I fixed it | **before I fix it** | 未发生的事用现在式 |
| If you'll still able to | **If you need to / If you're still able to** | *if* 后面不用 *will* |
| uninstall the docking station（指驱动） | **uninstall the docking station driver** | 分清硬件和软件 |
| it is help | **that really helps / it's helpful** | *help* 是动词 |
| has crash with | **became incompatible with** | 描述驱动不兼容 |
| gave by IT team | **provided / given by the IT team** | 被动语态用过去分词 |
| minitue / hep / id（is） | **minute / help / is** | 拼写 |
